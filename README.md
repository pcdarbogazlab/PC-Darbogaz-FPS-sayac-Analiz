# PC Darboğaz Lab v2

GitHub Pages için statik, bağımlılıksız PC analiz sitesi.

## Dosyalar
- `index.html` — ana sayfa
- `css/style.css` — tüm tasarım
- `js/data.js` — CPU, GPU, oyun ve sistem öneri verileri
- `js/app.js` — analiz ve sistem öneri mantığı
- `assets/favicon.svg` — site ikonu
- `robots.txt`, `sitemap.xml` — temel SEO

## GitHub Pages'e yükleme
Bu klasörün içindeki dosya ve klasörleri repository köküne yükleyin. `index.html` repository ana dizininde kalmalıdır.

## Not
FPS sonuçları yaklaşık bir karşılaştırma modelidir. Gerçek benchmark verisi değildir. Donanım puanları ve oyun profilleri zamanla güncellenmelidir.
